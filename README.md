# Meu Site Pessoal

## 📖 Descrição

Este projeto consiste em um **site pessoal desenvolvido em HTML** como atividade acadêmica.

O site apresenta diferentes páginas com informações sobre mim, minha cidade, meus sonhos, uma pessoa que me inspira e uma página temática dedicada aos meus doramas favoritos.

## 🎯 Objetivo

O objetivo deste projeto é **colocar em prática os conhecimentos básicos sobre HTML**, desenvolvendo uma página web e aplicando conceitos fundamentais da estrutura de documentos HTML.

Durante o desenvolvimento, são trabalhados conceitos como:

* Estrutura básica de documentos HTML;
* Títulos e parágrafos;
* Links;
* Imagens;
* Listas;
* Organização de conteúdo;
* Estruturação de páginas web.

## 💻 Tecnologias e ferramentas utilizadas

* **HTML5** — desenvolvimento e estruturação das páginas.
* **Visual Studio Code** — editor utilizado para desenvolver o projeto.
* **Git** — controle de versão do projeto.
* **GitHub** — armazenamento e publicação do projeto.
